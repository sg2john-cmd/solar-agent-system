# Commercial Use & Licensing — Solar Agent System (v17)

## What's free, what isn't

| Use | Permission |
|-----|-----------|
| Research, academic study, personal projects | ✅ Free (study + modify as needed) |
| Non-commercial redistribution | ✅ Free with attribution to the author |
| Commercial use (products, paid services, SaaS, embedding in sold software) | 🔒 Requires a commercial license from the author |

## Why this model

The framework was built by one person over an extended period. The code is shared openly so it can be tested, critiqued, and proven — but if someone builds a business on top of it, they're expected to put something back. That's the whole policy: **if you gain money from it, we talk.**

## License types (available)

1. **Personal/Research** — nothing to sign; see terms above.
2. **Commercial License** — one-time or revenue-share arrangements, scoped per project. Contact the author for current rates and terms.
3. **Collaboration / contribution agreements** — if you want to contribute features upstream while using it commercially, let's make that official in writing first.

## How to request a license

Contact: [sg2john-cmd](https://github.com/sg2john-cmd) (GitHub). Include what you intend to build and how you'd monetize it — quotes are informal and fast.
