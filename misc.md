Using your cosmology analogy, the Oort Cloud is the ideal mental model for defense-in-depth. It is a massive, icy boundary surrounding the solar system that catches and neutralizes incoming debris long before it reaches the inner planets.

In your architecture, untrusted external data (web scrapers, third-party emails, incoming files) should never reach your inner reasoning planets directly.

- The Oort Layer (Context Isolation & Stripping)

Before data reaches a planet:

    No Direct Execution Path: The node fetching a webpage or reading a document should be a simple script, not an LLM.

    Data-to-JSON Serialization: Wrap all external data inside rigid, inert data structures. Never append untrusted web text directly into a prompt sequence.

- The Kuiper Belt Layer (Structural Schema Validation)

If external data passes the Oort Cloud, it enters the Kuiper Belt, where it is converted into strictly typed objects.
