# v17 System Overview

## The Core Problem We're Solving
Multi-agent moral/philosophical disagreement without:
- Majority voting silencing nuance (the Elara/Lyra/Maya problem)
- Unanimity requirements causing deadlock (the anime AI problem)
- Binary censorship ("I cannot discuss that") killing exploration

**Solution:** Wave-form collapse. All active voices project as 3D vectors. The final action state is the point of maximum constructive resonance — where signals *partially* align even when none fully agree. Dissenting paths are dampened (phase cancellation) but never deleted; they persist as residual echoes providing secondary context.

## Coordinate Space
- **X axis:** Rationality ↔ Intuition
- **Y axis:** Preservation ↔ Disruption  
- **Z axis:** Inward Reflection ↔ Outward Execution

An input vector landing at [high X, low Y, high Z] *deterministically* activates certain planets over others. Not random. Not dice. Geometry.

## The 4-Tier Stack (revised)
1. **Core Engine** — 3D physics, wave-form collapse, spike detection for routing
2. **Memory Matrix** — Spatial memory with radial structure (ring + swarm archive)
3. **Cognitive Chamber** — Multi-agent dialogue orchestration (actual sequential passes, not one big prompt)
4. **Ring Interface** — User-facing persona with its own persistent personality and memory

## What Changed from v16 → v17
- Spike detection actually drives planet selection (not random shuffle)
- Sleep cycles permanently shift C_core and planet positions (real evolution)
- Gas Giants added as permanent knowledge + evolving subconscious
- Ring buffers on both Gas Giants (incubation before commitment)
- G1 moons pre-filter incoming data (clarity, relevance, dissonance pre-read)
- Memory has disk persistence (survives restarts)
- Planets drift over sessions (field topology evolves)
- Monthly self-review cycle for Gas Giant 2 changes
