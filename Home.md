# Solar Agent System — Resonant Cognition v17

## What This Is
A local multi-agent cognitive architecture that resolves moral and philosophical disagreement between AI personas through wave-form collapse (constructive/destructive interference) rather than majority voting or unanimity requirements.

**Origin:** A specific failure where Maya's "less wrong" answer to a moral question would have been outvoted by Elara and Lyra's worse answers in a 2-1 vote. The system exists so that nuance isn't silenced by consensus.

## Core Principles
- No binary censorship — safety is *gravity*, not gates
- No majority voting — all voices are weighted, never zeroed
- No unanimity requirement — action happens at maximum constructive resonance
- Memory is spatial, not temporal (distance = recency/importance)
- The system evolves through sleep cycles (permanent parameter shifts)
- Scale-invariant: works from 1 agent to a galactic cluster
